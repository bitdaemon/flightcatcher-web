# Data sources and attribution

| Data | Source | Used for | Status in this repo |
|---|---|---|---|
| Procedures (SIDs, STARs, approaches), fixes, runways for 506 US airports | FAA Coded Instrument Flight Procedures (CIFP), ARINC 424 | `Sources/SimCore/Resources/Airports/*.json`, generated by `Tools/cifp_to_package.py` | Included (derived). US federal government data, generally not subject to copyright. |
| Airport names, cities, IATA codes, and which airports have scheduled airline service (used to choose the bundled set) | OurAirports (ourairports.com), public domain | Airport index and picker, via `Tools/fetch_places.sh` | Included (derived) |
| Live wind | NOAA Aviation Weather Center METAR API (aviationweather.gov) | Optional live weather, fetched at run time | Not stored; free, no key, rate limited |
| ICAO Doc 4444 | ICAO | Phraseology reference during development | **Not included.** Copyrighted. |
| Airline names and callsigns | Public knowledge | Flavour for generated traffic | Included. Trademarks belong to their owners; no affiliation. |

Raw downloads (`Data/`, FAACIFP18) are not committed. To regenerate packages, download CIFP from the FAA, place it at `Data/cifp/FAACIFP18` and run `python3 Tools/cifp_to_package.py --cifp Data/cifp/FAACIFP18 --airline` (all bundled airports; needs `Data/places/airports.csv` from `Tools/fetch_places.sh`) or list ICAO codes such as `KBOS`.

This file is a good-faith summary, not legal advice. Check the current terms of each source before redistributing.
